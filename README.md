# Support Desk Simulation

Service desk workflow simulation focused on ticket handling and technical support operations.

## About the project

This project was created to practice basic front-end development and simulate a common help desk workflow. It allows the user to create, update, filter and delete support tickets.

## Features

- Create support tickets
- Set ticket priority
- Change ticket status
- Filter tickets by status
- Delete tickets
- Save tickets using LocalStorage

## Technologies

- HTML5
- CSS3
- JavaScript

## How to run

Open the `index.html` file in your browser.

## Project purpose

This project is part of my learning path in Systems Analysis and Development, with focus on IT support, help desk routines and JavaScript practice.
